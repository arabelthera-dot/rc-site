# Вопросы дня из фактов по шаблону (пункт 75, r713c-voprosy, 10.11.2026)

    node scripts/voprosy-iz-faktov.mjs izobreteniya 01-01               # черновик → data/predlozheniya/voprosy/izobreteniya/01-01.json
    node scripts/voprosy-iz-faktov.mjs ne-sdayutsya 01-06,01-15 --sverka # плюс сверка с викториной карточки дня
    node scripts/voprosy-iz-faktov.mjs ne-sdayutsya 01-06 --suho         # только напечатать

Ручной инструмент, не в CI и не в сборке. Берёт 15 фактов (10 + 5) из `src/data/utverzhdeno/<музей>/ММ-ДД.json`
и пишет файл-предложение `data/predlozheniya/voprosy/<музей>/ММ-ДД.json`. Утверждённое и `src/content/dni-shablon`
не трогает: вопросы в карточку переносит редактор.

## Как устроены вопросы в утверждённых днях
Поле `quiz.voprosy[]` карточки `src/content/dni-shablon/<музей>/ММ-ДД.yaml`: `q` — вопрос, `o` — варианты,
`a` — номер верного (с нуля), `e` — объяснение. Из 66 карточек январей: 5 вопросов по 4 варианта — 32,
5 по 3 — 22, остальные 12 — по 2–3 вопроса; `ball` обычно 10. Виды: «Когда…» (дата), «Сколько…» (число, неверные
×10: «Около 6000 / 600 / 60 / 6»), «Кто…», «Что/чем…», «Да/нет». Неверные варианты написаны вручную.

## Что делает черновик
5 вопросов по 4 варианта, один вопрос на факт, не больше двух одного вида. Сначала факты со словами «первый/впервые»
(«что первым»), затем заголовки фактов, затем подробности. Вопрос — предложение факта с пропуском «…».
- «кто» — фамилия в именительном; неверные — фамилии из 6 ближайших утверждённых дней музея;
- «когда» — полная дата или «В ГГГГ году»; неверные — даты того же вида из соседних дней, не ближе 2 лет;
- «сколько» — число с единицей; неверные — ×10, ÷10, ÷2.
Служебные поля: `iz` — номер факта, `shablon`, `klyuch`.

## Проба на 3 утверждённых днях (`--sverka`, затем глазами)
| день | утверждённых вопросов | совпало по смыслу | что совпало |
|---|---|---|---|
| izobreteniya 01-01 | 3 | 0 | утверждённые — про АТП-1, 1939/1948, экран 18 см; этого нет среди 15 фактов дня |
| ne-sdayutsya 01-06 | 5 | 1 | «сколько бойцов в контратаке» ↔ «от трёх рот газ оставил около 60» |
| ne-sdayutsya 01-15 | 5 | 3 | 104 человека на льду; Молоков и парашютные ящики; спасли всех 104 |
| итого | 13 | 4 | |

Машинная сверка: «тот же ответ» — ключ ответа черновика есть в утверждённом ответе; «тот же факт» — ≥3 общих основ
слов. Глазами проверены все 15 вопросов черновика: верный ответ во всех стоит в факте дословно. Изъяны: падежи
в «сколько» («52 человек», «23 батальонов»); вопрос — длинное предложение с пропуском, его надо сокращать.
Вопросы «чем/как/да-нет» и вопросы о главном событии вне 15 фактов инструмент не строит — их пишет редактор.
