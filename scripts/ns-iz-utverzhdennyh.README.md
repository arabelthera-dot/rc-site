# Машина «Русские не сдаются»: утверждённые факты → карточка дня (Р489, Р491)

`scripts/ns-iz-utverzhdennyh.mjs` переносит утверждённые Сергеем факты (`~/workspace/knowledge/ns-utverzhdeno/ns-ММ-ДД.md`) в карточку
`src/content/dni-shablon/ne-sdayutsya/ММ-ДД.yaml`. Слова утверждённого файла не меняются. Если машина чего-то не понимает, она громко останавливается (`ОСТАНОВ: …`, код 1).

## Команды

    node scripts/ns-iz-utverzhdennyh.mjs 01-01..01-31 --proverka            # только разобрать утверждённые файлы, ничего не писать
    node scripts/ns-iz-utverzhdennyh.mjs 01-03                              # карточка есть: заменить её факты утверждёнными
    node scripts/ns-iz-utverzhdennyh.mjs 01-06..01-10 --iz-staroy           # карточек нет: собрать из старой страницы, затем факты

Флаги:
- `--utverzhden ГГГГ-ММ-ДД` — дата утверждения, если в файле нет строки «Утверждено Сергеем ДД.ММ.ГГГГ».
- `--bez-adresa` — записать карточку, даже если замки адреса den не проходят. Тогда `adres` не ставится, а в шапке карточки перечислено, чего не хватает.

Код выхода: 0 — всё записано с `adres: den`; 2 — хотя бы у одного дня не прошли замки; 1 — останов.

## Строка «Источник:» — какие варианты понимает машина

Встречаются в 31 утверждённом январском дне (464 строки):
- «ИМЯ — URL», «ИМЯ (URL)», «ИМЯ, URL»;
- цепочки нескольких источников через «; », «, » или пробел;
- примечание после адреса: «URL (…)»;
- вложенное «донесение … (цитата в ИЗДАНИЕ (URL))»;
- после последнего адреса — ещё источник без адреса через «; » (так в 01-22).

На странице (`stranica`, `href`) стоит первый источник. Вся строка целиком идёт в `src`.

Громкий останов, если:
- в строке нет адреса http…;
- у адреса нет имени;
- после последнего адреса идёт текст, который не примечание в скобках и не следующий источник после «;» или «,».

## Режим --iz-staroy: карточка из старой страницы

Откуда машина берёт данные:
- `src/data/full-pages/ne-sdayutsya/ММ-ДД.html` — старая страница;
- `src/content/days/ne-sdayutsya/ММ-ДД.json` — запись дня;
- факты — из утверждённого файла.

Образец карточки — 01-01…01-05 (r602).

Что машина переносит со старой страницы: обложку (кадр героя; права и адрес — из записи дня), шапку, плашки, ролик, историю, аудиогид, викторину, календарь, источники, «Куда дальше» (без «Город-музей»), стрелки шапки. Пути ролика машина делает абсолютными от папки музея.

Разделы старой страницы, которых нет в шаблоне (put, trudno-poverit, vybor, dokument, chat-sec, razbor, mirovoy-kontekst, karta, interer…), машина не переносит. Она называет их строкой «ВЫБРОШЕНО». Если среди них визуализация дня (карта, каска — Р436), её переносит человек.

Старая страница без раздела `#istoriya` — громкий останов. В январе так у 01-07, 01-12…01-29: эти дни переводит человек или машина после доработки.

Чего старая страница не знает (машина пишет об этом строкой `·` под днём):
- привязку даты — пишется шаблоном из номера дня и плашки;
- звания — остаётся одно «Гость дня»;
- вопрос возврата — если на странице нет `MUSEUM_RETURN`, берётся первый вопрос викторины.

Готовую карточку машина не перезаписывает: если yaml уже есть — останов. Перед записью собранная карточка проходит схему музея. Затем на неё переносятся факты, как при обычном запуске. `adres: den` встаёт только при пройденных замках: у каждого факта отрывок и пометка, не меньше 6 разных кадров, есть ролик и аудиогид.

Если замки не прошли, карточка остаётся без `adres`. Живой адрес при этом не меняется: `den/ММ-ДД/` по-прежнему отдаёт старую страницу, а карточка видна только на `den-shablon/ММ-ДД/` для сверки.

## Как перевести день на yaml и не сломать живые адреса

1. `--proverka` на день. Если машина остановилась, исправлять утверждённый файл — дело человека, не машины.
2. `--iz-staroy` на день. Чего не хватает для `adres: den`, машина пишет строками `✗`.
3. Недостающее (кадры в `figures` или `kadr` у фактов, пометки достоверности) добавляет помощник дня в саму карточку. Факты руками не правят: исправляют утверждённый файл и перезапускают машину.
4. Машина без флага (или `--iz-staroy` при первом проходе) ставит `adres: den`. После этого `den/ММ-ДД/` рисует общий шаблон из yaml. Старый HTML, пока лежит в `src/data/full-pages/`, уходит на `den/ММ-ДД/staraya/` (noindex) — для сверки 1:1 и отката. Старые адреса `podvig-*.html` ведут на `den/ММ-ДД/` переадресацией, как и раньше.
5. `npm run build` — должен быть зелёным.
6. Старый HTML удаляется отдельной заявкой, когда yaml-страница принята. В той же заявке из снимка `scripts/dni-tolko-yaml.json` убирается строка этого дня. Снимок может только сужаться: новых строк в него не добавлять, хэши не обновлять. Пока у дня есть yaml-карточка, старый HTML не правят: замок `scripts/dni-tolko-yaml.mjs` в `npm run build` покраснеет на любой его правке. Убирать строку из снимка без удаления HTML нельзя: замок увидит в папке «новый файл старой страницы».

Откат дня: убрать `adres: den` из карточки (или удалить карточку). Тогда `den/ММ-ДД/` снова отдаёт старый HTML — он ещё лежит, пока не прошёл шаг 6.
