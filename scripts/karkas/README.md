# Машины каркаса

- `literatura.mjs` — каркас карточки дня из старой страницы музея «Великие русские книги и их авторы» (`--proba` — проба всех страниц, ничего не пишет); источник эпизода «Пяти историй», которого нет на старой странице, берётся из `src/data/karkas-dopolnenie/literatura.json` (`{"ДД-ММ": {"номер удара с 0": {"src", "url"}}}`; `{"ne_podtverzhden": "где искали"}` — удар не переносится и пишется в nety), Р494.
