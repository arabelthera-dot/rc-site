# Каркас карточки дня из старой страницы — договор адаптеров (Р493)

Диспетчер — `scripts/karkas-iz-staroy.mjs`. По имени музея он грузит `scripts/karkas/<музей>.mjs` и зовёт его разбор.

## Что адаптер обязан дать

```js
export function razobrat(html, json, den) → { ...поля карточки, nety: [...] }
```

- `html` — текст старой страницы `src/data/full-pages/<музей>/ММ-ДД.html`; если страницы нет — `null`.
- `json` — запись дня `src/content/days/<музей>/ММ-ДД.json`; если её нет — `null`.
- `den` — ключ дня «ММ-ДД».
- Поля — те же, что в `src/content/dni-shablon/<музей>/ММ-ДД.yaml` (образец — `ne-sdayutsya/01-01.yaml`). Только без `muzei`, `key`, `adres` и `fakty`: их ставит машина утверждённого (у НС — `scripts/ns-iz-utverzhdennyh.mjs --iz-staroy`).
- `nety` — список строк: чего на старой странице нет или что выброшено. Если блока нет, поле остаётся пустым (или отсутствует), имя блока идёт в `nety`. Работа не останавливается. В карточку `nety` не попадает: машина пишет его в шапку-комментарий YAML.
- Адаптер ничего не пишет на диск и ничего не придумывает. Источники кадров — только Госкаталог, музеи и архивы, а также материал дня. Википедии нет.

## Чем можно дополнить (по желанию)

- `material(den)` — цитаты и кадры дня из `~/workspace/knowledge/<музей>-material/ММ-ДД.md`. Это `{ fakty: Map<номер, {otryvok, href, stranica, pometka}>, kadry: [...] }`. Машина утверждённого берёт отсюда отрывок, адрес и кадр к факту.
- `kadrKartochki(kadrMateriala)` — кадр материала в виде кадра карточки (`kadr` из `src/lib/den-obshchee.mjs`), если кадр годен; иначе `null`.
- `--proba` — разобрать все старые страницы музея и напечатать «N из N» и строки `nety`. Если не все — код выхода 2.

## Проверка

```
node scripts/karkas-iz-staroy.mjs ne-sdayutsya 01-07     # один день: поля и «нет: …»
node scripts/karkas/ne-sdayutsya.mjs --proba             # все старые страницы НС
```

Чужие адаптеры (`scripts/karkas/<другой музей>.mjs`) пишет и правит только хозяин музея.
