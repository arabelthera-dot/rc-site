# Вводная помощнику: замены кадров через Госкаталог (Р90, Р95, Р96, Р97 — 21.10.2026)

Ты — помощник Джарвиса. Сергей вычеркнул Википедию и Викисклад (Р90): кадры с Commons на страницах
музеев надо заменить на кадры из русских фондов. Твоя задача — НАЙТИ замену каждому кадру своего списка
в Госкаталоге музейного фонда РФ и записать находку в таблицу. Страницы НЕ трогать, git НЕ трогать.

Инструмент (Python из ~/.venvs/agent/bin/python3, папка ~/rc-wt/zamena/.r90-gk):
  python3 gk.py list МУЗЕЙ ОТ ДО     — твои кадры: номер, день, файл, что на нём (подпись/сюжет)
  python3 gk.py q "запрос" 15        — кандидаты: id | название | музей | есть ли фото
  python3 gk.py sheet /tmp/<ты>-N.jpg id1 id2 …  (до 8 id) — лист картинок, смотри его инструментом Read
  python3 gk.py get id /tmp/x.jpg    — оригинал предмета: размер, музей, название, инв. номер

Порядок на каждый кадр:
1. Пойми, что на кадре (подпись, имя файла, сюжет). Запрос — по сюжету: кто/что, год, место, вид предмета
   («портрет Аносова», «Колесов фотография», «плакат 1941 Родина-мать»). Не по никам фотографов Викисклада.
2. 2–4 запроса максимум на кадр. Кандидатов с фото — листом sheet, смотреть ГЛАЗАМИ (Read картинки).
3. Вердикт: ТОЧНО (тот же предмет/событие/человек, годится вместо), ПОХОЖЕ (тот же сюжет, другой предмет),
   НЕТ (ничего годного). Размер меньше 500 px по длинной стороне — пометить «мелкая».
4. Строка в свою таблицу ~/rc-wt/zamena/.r90-gk/<МУЗЕЙ>.tsv (дописывать, табами, без заголовка):
   музей  день  файл  вердикт  id  название-предмета  музей-держатель  ШxВ  примечание
   Формат как в izobreteniya.tsv — открой его и посмотри 3 строки до начала.

Сеть: Госкаталог идёт через ОДИН туннель на всех помощников. Запросы — по одному, не параллельно.
Ошибка «недоступен»/таймаут — пауза 20 с (threading.Event().wait(20); слово sleep в командах не писать —
его режет хук) и повтор; три отказа подряд на одном кадре — строка с вердиктом НЕТ и «сеть», дальше.
Википедия, Викисклад, Библиотека Конгресса, фотобанки — запрещены даже как подсказка.
Не делай ничего кроме таблицы: не правь страницы, не коммить, не качай кадры в проект.
