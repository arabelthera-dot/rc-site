# Если некому продолжать

Короткая памятка: где всё лежит и как поднять сайт с нуля. Ключей и паролей здесь нет и не будет.
Подробно: `knowledge/esli-nedostupen-kto-to.md` и `knowledge/opis-dostupov.md` в AI_Projects.

## Где код и медиа

- Код сайта — GitHub `arabelthera-dot/rc-site`, ролики — `arabelthera-dot/rc-rolik`.
- Ночная копия всех 8 репозиториев (rc-site, rc-rolik, rc-rabochee и др.) — на нашем узле в `/srv/backup/git/`, 03:30 каждый день; раз в месяц — проба восстановления.
- Зеркало вне GitHub — `.github/workflows/zerkalo.yml`, включается секретами `MIRROR_GIT_URL` и `MIRROR_TOKEN`.
- Ролики (mp4) лежат в git этого репозитория и копией в `/srv/rc-media` на сервере сайта.

## Как собрать сайт с нуля

1. Node 22, полная история git (`git clone` без `--depth`).
2. `npm ci`, затем `RC_POISK=1 npm run build` — около минуты, итог в `dist/`.
3. Выложить `dist/` rsync-ом на сервер сайта в `/srv/rc-site/www` (так делает `deploy.yml`).
4. Если сервер недоступен — запасная копия на GitHub Pages, переключение домена: `knowledge/pereklyuchenie-na-zapasnoy.md`.

## Что машина делает сама

- «Сегодня» — ночная пересборка `deploy.yml` (21:07, 21:37, 22:07 UTC).
- Перевод — `perevod.yml` при каждом слиянии.
- Готовый ролик на сайт — `rolik-na-sait.yml` каждые полчаса.
- Каналы — `kanaly.yml` в 06:00 (пробный режим до «да» Сергея).
- Проверка живого сайта — `smoke.yml` каждые 3 часа.

## Что пока руками и почему

- Новый день — пишет исполнитель: нужен текст и источники, машина их не придумает.
- Рендер ролика — запускает исполнитель после утверждения дня.
- Выкладка медиа на сервер — `media.yml`, ручной пуск: копирует большие файлы, нужен глаз.
- Выход дня по дате (`RC_PO_DATE`) готов, но выключен: включение меняет вид сайта, нужно решение Сергея.
