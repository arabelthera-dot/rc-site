# Один помощник на весь месяц музея — порядок (п. 55, Р474)

Задача ставится одна на месяц музея, а работают куски по 3 дня: так решил Сергей (Р474, 03.11.2026). На проверку и подбор фактов —
не больше 3 дней на помощника, на механику (`--legko`) — не больше 5. Месяц машина режет сама. Руками задания по дням
не пишутся и не запускаются.

Почему именно так: r631 (16 дней) и r633 (15 дней) упёрлись в 251 ход, недоделанное перезапускали, и вышло ~7 млн лишних токенов.
4 дня проверки заняли 156 ходов. Потолок куска сейчас 90 ходов (Р491, `HODOV_TYAZH` в `~/workspace/tools/pomoshchnik.py`).

## Порядок

1. **Одно задание на месяц.** Файл задания пишется один раз на музей и месяц. Место дней в нём — метка `{DNI}`,
   например: «Музей «Русские не сдаются», февраль, дни {DNI}: …». Конкретные числа в задание не вписываются.
   Строка вида `02-01…02-28` без `--dni` не запустится: сторож Р491 в `start()` отказывает, если дней больше 3.
2. **Запуск одной командой:**
   `python3 ~/workspace/tools/pomoshchnik.py start ИМЯ ФАЙЛ --dni 1-28` (механика — добавить `--legko`).
   Название музея в задании — полное, дословно `title_ru` из `src/data/museums.json`.
3. **Машина режет месяц** (`narezat()`): дни идут подряд кусками по 3 (по 5 с `--legko`). Пример на 31 день:
   1–3, 4–6, …, 28–30, 31 — получается 11 кусков. Имя куска — `ИМЯ-01-03`, `ИМЯ-04-06`, …, `ИМЯ-31`. В каждый кусок
   вписываются строки `# max-turns: 90` (60 с `--legko`) и `# stranica`, а вместо `{DNI}` — его дни.
4. **Сколько мест — столько запусков.** Свободных мест `MAX_ZHIVYH` (сейчас 10) минус число живых помощников. Столько кусков
   запускаются сразу, остальные ложатся в `~/workspace/logs/pomoshchniki/ochered/` под именами `ЧЧММNN-ИМЯ-…`.
   Номер NN идёт по порядку дней, поэтому очередь идёт с начала месяца.
5. **Очередь разбирает будильник** (`~/workspace/tools/budilnik-pomoshchnik.py`, `iz_ocheredi()`, раз в минуту, ночью
   23:00–07:00 МСК — нет): есть место — следующий кусок уходит в `start`, файл — в `ochered/zapushcheny/`. Потолок ходов
   кусок несёт с собой строкой `# max-turns`.
6. **Сдача по дням, по порядку.** Каждый кусок пишет `./dni/ММ-ДД.txt` на каждый готовый день сразу (Р495).
   Дни Сергею уходят подряд, с начала месяца (Р559). Каждый кусок — своя ветка и своя заявка.
7. **Обрыв куска.** Кусок продолжается с места (`podnyat`, та же беседа, Р496). Месяц заново не режется.

## Чего не делать

- Не давать одному помощнику больше 3 дней (5 на механику) через `--mnogo-dney`. Этот ключ — только для машины, которая
  проходит все дни сразу (скрипт, не страницы).
- Не делить месяц руками на свои файлы. Рядом с очередью появится вторая, и куски задвоятся (сторож дублей ловит только то же имя или тот же файл задания).
- Не трогать карточки другого месяца и другого музея (Р553, Р558): в задании — только текущий музей и его месяц.

## Откат

Не передавать `--dni`: `start` запускает одно задание, как раньше, а сторож Р491 не даст вписать в него больше 3 дней.
