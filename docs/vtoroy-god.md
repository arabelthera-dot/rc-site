# Второй год: запас кандидатов и герой года (пункты 7 и 11 очереди 0, Р616)

Сейчас на каждой дате каждого музея — один день (`src/content/days/<музей>/ММ-ДД.json`, утверждённый текст
`src/data/utverzhdeno/<музей>/ММ-ДД.json`). Через год на ту же дату нужен другой герой. Здесь — где лежат данные
для этого и в каком виде. Страницы, карточки дней и сборка не меняются; всё новое выключено.

## Пункт 7. Запас кандидатов на дату

Цель — 7–8 кандидатов на каждую дату каждого музея, чтобы на второй (третий…) год было из чего выбрать.
Кандидатов не придумывают и отдельно не ищут: помощник записывает то, что ему попалось по пути, пока он делал свой день.

**Как записывать (помощнику).** В папке своего наряда в журнале — `~/workspace/logs/pomoshchniki/<наряд>/kand.tsv`
(или несколько: `kand-01.tsv`, `kand-02.tsv`). Через табуляцию, первая строка — заголовок:

    muzei	data	imya	sobytie	god	baza	ssylka
    izobreteniya	03-05	<кто>	<что случилось>	<год>	goskatalog	https://goskatalog.ru/portal/#/collections?id=…

- `muzei` — slug музея из `src/data/museums.json`;
- `data` — дата ММ-ДД, на которую приходится событие;
- `imya` — кто (или что, если героя-человека нет);
- `sobytie` — что случилось, одной строкой;
- `god` — год события;
- `baza` — id базы из `src/data/spravochniki/bazy.json` (раздел `razresheny`), как в пункте 15;
- `ssylka` — точный адрес страницы, где это написано.

Пустое поле, база не из списка, адрес Википедии — строка не берётся. Записать «по памяти», без адреса, нельзя.

**Как собирается (машина).** `python3 tools/zapas.py` читает все `kand*.tsv` журнала и пишет
`data/zapas/zapas.json`:

    "dni": {
      "izobreteniya/03-05": [
        {"imya": "…", "sobytie": "…", "god": "…",
         "istochnik": {"baza": "goskatalog", "ssylka": "https://…"},
         "nashel": "logs/pomoshchniki/<наряд>/kand.tsv",
         "kartochka": "lyudi:…"}
      ]
    }

Повторы (тот же музей, дата, имя и событие) склеиваются, больше 8 на дату не держится. Если имя уже есть
в `src/data/spravochniki/kartochki.json` (пункт 30), машина ставит номер карточки — `kartochka`.
Отказанные строки машина печатает с причиной; сколько дат набрали 7 — тоже. Файл руками не правят.
Сборка сайта `zapas.json` не читает.

На 09.11.2026 в журнале нет ни одного `kand.tsv`, поэтому `zapas.json` пуст: 0 записей. Списки кандидатов
по космосу (`~/workspace/memory/agents/claude2/kosmos-*.json`) не взяты: их источник — cosmoworld и ГМИК,
этих баз нет в `bazy.json`.

## Пункт 11. Герой текущего года

Решение: на странице даты — герой текущего года; у героя своя постоянная карточка; номера года в адресе нет.

- **Адрес не меняется.** Страница даты остаётся `/muzei/<музей>/den/ММ-ДД/`. Что на ней — решает год, а не адрес.
  Старые ссылки, закладки и поиск не ломаются.
- **Герой — карточка, а не день.** Каждый герой — постоянная карточка `tip:slug` из
  `src/data/spravochniki/kartochki.json` (пункт 30). Прошлогодний герой не пропадает: его карточка остаётся,
  в поле `dni` у неё — даты, где он был героем.
- **Кто в каком году.** Файл `data/gody/geroi-goda.json`:

      {
       "vklyucheno": false,
       "nachalo_goda": "01-01",
       "pervyy_god": null,
       "dni": {
         "izobreteniya/01-26": [
           {"god": 1, "kartochka": "lyudi:abramov-g", "den": "src/data/utverzhdeno/izobreteniya/01-26.json"},
           {"god": 2, "kartochka": "lyudi:…", "den": "…"}
         ]
       }
      }

  `god` — номер года проекта (1, 2, 3…), не календарный год; `pervyy_god` — календарный год, с которого
  считается год 1 (ставит Сергей при включении); `den` — утверждённый текст этого героя на эту дату.
  Года 1 в файле можно не писать: год 1 — то, что стоит сейчас.
- **Откуда второй год.** Кандидат на год 2 берётся из запаса `data/zapas/zapas.json` по той же дате,
  проходит обычный путь дня (текст → утверждение Сергея), и только утверждённый попадает в `geroi-goda.json`.
- **Выключено.** Пока `vklyucheno: false`, страницы файл не читают и показывают то, что сейчас.
  Включение — отдельной заявкой с «да» Сергея: тогда страница даты выбирает запись по номеру текущего года
  (по московскому времени, с `nachalo_goda`), а если на этот год записи нет — показывает год 1.
