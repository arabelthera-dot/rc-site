# Авторы ссылок-источников против реестров (М78, AI_Projects #2357, 04.11.2026)

**Что делает.** Е1 (`src/lib/zakon.mjs`) ищет имена из реестров только в нашем тексте. Автора чужой статьи, на которую
ссылается день, он не видит. Пример: Родионов, 23 янв., ссылка на kommersant.ru/doc/476951, автор — Олег Кашин.
Шаг `avtory-ssylok` в `proverka.yml` собирает все внешние адреса из `src/content/days/**`, шаблона дня и `href`
полных страниц `src/data/full-pages/**`. Для каждого адреса берёт автора из кэша `data/avtory-ssylok.json` и сверяет
его через `sverkaTekstov` из `zakon.mjs`: то же сопоставление имён, те же исключения. Код:
`src/lib/avtory-ssylok.mjs`, `scripts/avtory-ssylok.mjs`, пробы — `scripts/avtory-ssylok.test.mjs`.

- Автор-иноагент — `::error::` с днём, адресом, автором и именем из реестра, шаг красный.
- Адреса нет в кэше или страница не скачалась (например, 403 у goskatalog) — `::warning::` «не проверено»,
  шаг зелёный.
- Однофамилец снимается строкой в `data/reestry/isklyucheniya.json` с ключом `<музей>/<ключ>|<вариант>`, как в Е1.
  Спорный случай — в раздел «ждёт решения Сергея, r380».

**Флаг.** Переменная репозитория `AVTORY_SSYLOK=0` выключает шаг: и скрипт, и пробы.

**Наполнить кэш** (локально, сеть только здесь; CI не качает). Через российский выход:
`RF_PROXY=socks5h://rf-proxy:1080 node scripts/avtory-ssylok.mjs --napolnit`. Скачиваются только адреса, которых нет
в кэше, каждый один раз. Ключ `--povtor` повторяет прошлые ошибки. Есть ключи `--pauza 1500` (мс), `--taymaut 20` (с),
`--potoki 6` и `--skolko N`. Одну страницу можно проверить так: `node scripts/avtory-ssylok.mjs --url <адрес>`.
Обновлённый `data/avtory-ssylok.json` коммитится вместе с днём.

**Откат.** Быстро — `AVTORY_SSYLOK=0`. Совсем — удалить шаг `avtory-ssylok` из `.github/workflows/proverka.yml`.
Код и кэш ни на что больше не влияют.
