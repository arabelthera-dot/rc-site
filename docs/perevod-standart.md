# Язык цитаты и отпечаток русского текста у перевода (пп. 43, 44 очереди 0, Р669); коды и адреса переводов (пп. 145–150 очереди 2)

Только устройство данных. Новых проверок сборки нет (Р627), готовые дни и файлы строк не меняются.

## 43. Язык цитаты — поле `yazyk` у записи цитаты

Цитата в карточке дня (`citaty`, тип — `src/lib/forma-dnya.mjs`, `citata`) получает поле `yazyk` — код BCP 47
из закрытого списка `YAZYKI_CITAT`:

| Код | Язык |
|---|---|
| `be` | белорусский |
| `cu` | церковнославянский |
| `ru` | русский — можно не писать |

Поля нет — цитата русская, как у всех дней до сих пор. Пример:

    { "kto": "Янка Купала", "gde": "…", "tekst": "…", "istochnik": "…", "yazyk": "be" }

Зачем: машина перевода не переводит такую цитату как русскую строку, а шаблон может поставить ей `lang="be"`
(чтение экранным чтецом, переносы, поиск). Вывод `lang` на страницу — отдельный шаг шаблона, здесь его нет.
Поле вносит машина дозаполнения карточек; руками карточки не правятся.

## 44. Отпечаток русского текста у перевода — раздел `_otpechatki`

Файл строк (`src/data/stroki.json`, `src/data/igry/stroki/<музей>-<ММ-ДД>.json`) устроен так:
`{ "_": пояснение, "ru": { ключ: текст }, "<код>": { ключ: перевод } }`. Рядом добавляется раздел:

    "_otpechatki": { "<код>": { "<ключ>": "<отпечаток русской строки, с которой переводили>" } }

Отпечаток — первые 16 знаков sha256 от русской строки в NFC (`otpechatok()` в `src/lib/otpechatok.mjs`).
Раздел отдельный, переводы остаются строками: `stroka()` и `igraNaYazyke()` читают `fayl[код][ключ]` как раньше.

Машина перевода:

- пишет перевод через `zapisatPerevod(fayl, код, ключ, перевод)` — отпечаток кладётся сам;
- перед переводом зовёт `ustarevshie(fayl)` — список `{ code, kluch, prichina }`, что делать заново:
  - `ru-izmenilsya` — русская строка сменилась после перевода;
  - `net-otpechatka` — перевод сделан до п. 44, с какого текста — неизвестно;
  - `net-ru` — русской строки больше нет, перевод лишний.

Сейчас: в `src/data/stroki.json` 101 арабская строка без отпечатка (`net-otpechatka`) — задним числом
отпечатки не ставятся: неизвестно, с какого русского текста их переводили, запись «перевод свежий» была бы неправдой.
Их отпечатает машина перевода при следующем проходе.

## 161. Поиск на языке страницы — Pagefind по `<html lang>`

Индекс поиска (src/integrations/poisk.mjs) строится без `forceLanguage`: Pagefind сам делает отдельный индекс на каждый
язык по `<html lang>` страницы и режет слова по правилам языка (китайский — по словарю, хинди — по пробелам и знакам).
Язык страницы ставит `langStranicy()` по коду из пути (`/<код>/muzei/…`); русские страницы и их индекс — как были.
Проба: «导弹» в китайской странице — было 0 найденных, стало 1; индексы hi, ru, zh.

## 162. Потолок длины перевода — src/lib/potolok-dliny.mjs

Узкие места — хук и заголовок дня (`lead.hook`, `lead.h1`), заголовок игры, подписи (`*.podpis`), пункты меню дня,
кнопки игр (`varianty.N.tekst`, `podpisi.N.tekst`, `*.knopka`). Перевод может быть длиннее русского на 30 %, для de, fr,
es, pt, hi и для строк до 20 знаков — на 50 %. Знаки считаются графемами (Intl.Segmenter). Превышение — не ошибка:
scripts/perevod-dnya.mjs печатает «длинно: <код> <ключ> <длина> > <потолок>», строка попадает в заявку avto/perevod-…
Отдельного сторожа в CI нет.

## 164. Тексты ручных январских игр — src/data/igry/stroki/<музей>-<ММ-ДД>.json

Разметка и скрипты январских игр не меняются. Ключи `<музей>.<ММ-ДД>.igra.<html|js|dop>.<номер>[.knopka]` указывают на
места с кириллицей (src/data/igry/stroki-ruchnyh.mjs); `ruchnayaNaYazyke()` подставляет перевод на то же место.
Русские строки пишет `node scripts/stroki-ruchnyh-igr.mjs`; `--proverit` — ru-подстановка байт в байт равна исходнику
(31 из 31). Языки пишет машина перевода тем же проходом, что и день.
## 145. Код языка — BCP 47, с письмом и страной, где нужно

Один список языков — `src/data/yazyki.json`, поле `code` — тег BCP 47: он же приставка адреса, `lang`, `hreflang`,
`inLanguage` и ключ раздела в `src/data/perevod/<музей>-<ММ-ДД>.json`. Китайский — `zh-Hans` (упрощённое письмо;
у `zh` письмо не определено). Письмо и страна — только когда без них язык неоднозначен (`zh-Hans`, `pt-BR`);
`ru`, `en`, `ar`, `hi` — без подтегов. Переводчику (`scripts/perevod-dnya.mjs`) передаётся основной подтег (`zh`).

## 146. Хвост адреса не переводится

Перевод дня — `/<код>/muzei/<музей>/den/<ММ-ДД>/`: приставка языка, остальное — как у русской страницы
(`putNaYazyke` / `razobratPut` в `src/lib/yazyki.mjs`). Проверено разово, не шагом CI (10.11.2026): 35 музеев ×
372 ключа × 4 языка = 52080 адресов, хвост тот же, разбор обратим, ошибок 0.

## 149, 150. hreflang в карте сайта и связь перевода с оригиналом

Язык у страницы дня есть, когда он `ready:true` и у дня есть его раздел в файле перевода. Тогда:
- `<link rel="alternate" hreflang>` — русский, языки страницы и `x-default` (русская);
- карта сайта — `<xhtml:link rel="alternate">` с теми же языками, только если переведённая страница собрана;
- JSON-LD — `inLanguage`, у русской `workTranslation`, у перевода `translationOfWork` со ссылкой на русскую.
Перевода нет — всё выключено, вывод прежний. Проба (10.11.2026, вне репозитория): день izobreteniya/01-02 с пробным
машинным переводом хука (бесплатный MyMemory; en, ar, zh) — пометки, карта и связь появились только у этого дня.
Китайский пробный перевод исказил смысл — машинный перевод только черновик для редактора.

## Как это делают в мире

- Weblate при смене исходной строки ставит её переводам состояние «Needs editing»:
  https://docs.weblate.org/en/latest/user/translating.html#translation-states
- gettext хранит прежний исходник у неточного перевода (`#| msgid`, флаг fuzzy):
  https://www.gnu.org/software/gettext/manual/gettext.html
- Коды языков BCP 47 (`be`, `cu`) — реестр IANA: https://www.iana.org/assignments/language-subtag-registry ,
  атрибут `lang` в HTML: https://html.spec.whatwg.org/multipage/dom.html#the-lang-and-xml:lang-attributes
- Поиск по языкам — Pagefind: https://pagefind.app/docs/multilingual/
- Рост текста при переводе — W3C: https://www.w3.org/International/articles/article-text-size ,
  ограничение длины у Weblate: https://docs.weblate.org/en/latest/admin/checks.html#maximum-length-of-translation
- hreflang, x-default и `xhtml:link` в карте сайта (Google):
  https://developers.google.com/search/docs/specialty/international/localized-versions
- Выбор тега с письмом и страной (W3C): https://www.w3.org/International/articles/language-tags/
- `translationOfWork` / `workTranslation`: https://schema.org/translationOfWork
