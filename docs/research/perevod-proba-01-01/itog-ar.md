# Проба машинного перевода дня на арабский (п.142 очереди 2, Р603)

День: «Первая в мире сеть кабельного телевидения» (январь музея изобретений), 83 строки: хук 2, факты 30, подписи 3, обложка 1, викторина 18, игра «Сигнал по кабелю» 29. Адрес страницы не переводился.
Словарь имён: glossary-ar.tsv (12 имён, рус → ar). Сравнение: `python3 sravnenie-ar.py`.
Обратный перевод на русский у обоих — Argos ar→en→ru.

| | А: Argos + словарь | Б: модель по словарю |
|---|---|---|
| секунд на день×язык (83 строки) | 125 | 84 |
| имена верно | 21 из 23 | 22 из 23 |
| мусор `&quot;` в тексте | 4 строки | 0 |
| длина ar/ru, средняя (макс) | 0,86 (1,33) | 0,92 (1,33) |
| сходство обратного перевода с ru (машинное) | 0,55 | 0,49 |

Машинное сходство обратного перевода обманывает: оно выше у Argos, потому что Argos переводит туда и обратно одной моделью и упрощает фразу одинаково. Глазами Б лучше: у А теряется «кабельного», «дрогнет» становится «процветать», кавычки идут HTML-кодом, строка викторины про АТП-1 сломана целиком.

## Три образца
1. RU «Первая в мире сеть кабельного телевидения». А: أول شبكة تلفزيونية في العالم → «Первая телевизионная сеть в мире» (кабель потерян). Б: أول شبكة تلفزيون كابلي في العالم → «Первая в мире сеть кабельного телевидения».
2. RU «АТП-1 — «абонентский телевизионный приёмник»: без антенны и настройки, картинка приходила по кабелю». А: "رقم ATP-1" "مستقبل تلفزيوني مقتبس" … → «Нет, АТФ-1». Б: ATP-1 — «جهاز استقبال تلفزيوني للمشتركين»: بلا هوائي وبلا ضبط… → «ATP-1 — "Телевизионный приемник для абонентов": никакого эфира и никакого захвата, а картинка доходила по кабелю».
3. RU «нажмёшь не ту деталь — она дрогнет». А: فإنه سيزدهر → «она будет процветать». Б: فستهتز → «вы потрясетесь» (ar верно «она дрогнет», ошибка уже в обратном переводе Argos).

## Где ломается
- Справа налево: 43–44 строки из 83 смешивают арабский с цифрами, латиницей (ATP-1), эмодзи (📡 قوِّ الإشارة). Вёрстке нужен `dir="rtl"` у `<html lang="ar">` и `<bdi>`/`unicode-bidi: isolate` для чисел и названий, иначе тире и скобки уезжают. Кнопки игр с эмодзи в начале строки — проверять глазами.
- Китайский без пробелов (для сведения, делают другие): перенос строк только `word-break`/`line-break: strict`, подсчёт длины по символам врёт.
- Длина: арабский не длиннее русского (макс 1,33) — кнопки игр не переполнятся; ширину держит вёрстка, не перевод.

## Рекомендация
Б — перевод моделью по словарю, Argos — только для чернового обратного перевода-проверки. Б быстрее (84 с против 125 с на день×язык) и без поломок.
Оценка на 365 дней × 2 музея × 50 языков = 36 500 день×язык: Б ≈ 36 500 × 84 с ≈ 852 ч ≈ 35 суток одного потока (10 потоков — 3,5 суток), расход — лимиты модели; А ≈ 1 270 ч ≈ 53 суток одного ядра, бесплатно, но с поломками выше. Языки, которых нет в Argos, — только Б.
