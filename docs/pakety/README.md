# Пакет «музей + месяц» (п. 51, Р631)

Одна папка на музей и месяц: `docs/pakety/<музей>/<ММ>/README.md`. Это вход для помощника, который делает месяц:
где лежат карточки, по какому стандарту они пишутся, какие дни брать образцом и чем проверить себя до сдачи.

Пакет только ссылается на готовое, ничего не копирует. Карточки дней живут в одном месте — `src/content/dni-shablon`
и `src/content/days`; копия дня в пакете стала бы вторым источником и разошлась бы с оригиналом.

## Что в пакете

1. Музей — полное название из `src/data/museums.json` (`title_ru`) и месяц.
2. Ключи дней месяца и куда ложится карточка.
3. Стандарт дня — `docs/standart-dnya.md`, с ключа 02-01.
4. Образцовые дни — путь к карточке и чем она образец. Образец — только утверждённый день, который проходит
   проверку до сдачи без строк «нет пункта». Пока таких дней в месяце нет — пишется, что их нет, и почему.
5. Проверка до сдачи — раздел «Проверка до сдачи» в `docs/standart-dnya.md`.

## Как пакет пополняется

Первый утверждённый день месяца, у которого проверка до сдачи чистая, вносится в пакет строкой «образец» —
путь к карточке. Двух-трёх образцов на месяц хватает. День переделали — строка остаётся, она ведёт на тот же файл.
Новый месяц — новая папка `<ММ>` по этому же описанию.
