# Музей «Что изобрели русские первыми в мире» — февраль

Пакет «музей + месяц» по описанию `docs/pakety/README.md`.

## Дни

Ключи 02-01…02-28. Событие 29 февраля стоит на 02-28 с объяснением в `data_uslovnaya` (пункт 3 стандарта).
Карточка страницы — `src/content/dni-shablon/izobreteniya/ММ-ДД.yaml`, запись дня — `src/content/days/izobreteniya/ММ-ДД.json`.

## Стандарт

`docs/standart-dnya.md` — все дни февраля под ним (ключ от 02-01).
Только у этого музея: пункт 76 — игра данными, `docs/igry-standart.md`.

## Образцы

Утверждённых дней февраля пока нет. Январь образцом не годится: на 09.11.2026 каждая из 31 карточки января
`src/content/dni-shablon/izobreteniya` под стандартом февраля даёт 26 строк «нет пункта» (январь писали до стандарта).

Пока образцов нет, берутся части:

| Что | Где | Чем образец |
|---|---|---|
| Поля формы дня | `docs/forma-dnya-obrazec.json` | запись дня с полями очереди 0 (изобретения, 01-13) |
| Игра 02-01, 02-02 | `docs/igry-obrazcy/kazhdomu-svoyo-mesto.json` | механика данными для февраля |
| Игра данными целиком | `docs/igry-obrazcy/razbey-ldiny-po-prochnosti.json` | скопировать и поменять тексты и числа |

Первый утверждённый день февраля с чистой проверкой до сдачи вносится сюда строкой:
`| образец | src/content/dni-shablon/izobreteniya/02-ДД.yaml | чем хорош |`.

## Проверка до сдачи

`docs/standart-dnya.md`, раздел «Проверка до сдачи»: `npx astro sync` и проверка карточек `kartochki()`.
Для полной сверки файлов — `git sparse-checkout add /public/muzei/izobreteniya/`.
