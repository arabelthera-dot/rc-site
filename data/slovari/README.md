# Словари для scripts/tipograf.mjs

- `yo-safe.txt.gz` — словарь «безопасных» слов с буквой ё (14 645 строк, формы в скобках), без изменений из
  проекта eyo-kernel (Денис Селезнёв, лицензия MIT): https://github.com/hcodes/eyo-kernel/blob/master/dictionary/safe.txt
  «Небезопасные» слова (все/всё, небо/нёбо) не взяты нарочно — их ставит человек.
