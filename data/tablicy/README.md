# Утверждённые таблицы года — источник правды ядра

Здесь лежат утверждённые Сергеем таблицы года всех музеев (ядро, шаг 2; 19.10.2026).
Запись дня `src/content/days/<музей>/ММ-ДД.json` строится из таблицы; правка записи мимо таблицы
роняет заявку (задание `tablicy` в `.github/workflows/proverka.yml`).

Изменить день — правка таблицы здесь же, в той же заявке, затем `node scripts/tablicy/razbor.mjs --zapis`.
Откуда перенесены — поле `istochnik` в `scripts/tablicy/adaptery.json`.
