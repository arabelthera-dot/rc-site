## 1. Как устроено

- День музея — **одна карточка**: `src/content/days/<музей>/<ММ-ДД>.json`. Страница дня, календарь и
  витрина музея собираются из карточек сами; руками их не верстают.
- Музеи — `src/data/museums.json`. Имя музея — только `title_ru` оттуда, дословно и полностью.
- Шаблоны — `src/pages/` (главная, музей, календарь, день, карта). Вид — только `public/assets/*.css`.
- Интерактивы и движки — `public/assets/*.js`, те же, что на старом сайте, без переделки.
- Превью: https://arabelthera-dot.github.io/rc-site/ · карта стандарта: https://arabelthera-dot.github.io/rc-site/karta/

## 2. Где правда — до и после переключения

- **До 17.10.2026 21:00 МСК (переключения адреса)** правда — старый репозиторий `rc-museum-preview`: утверждённые

| `museum`, `key` | slug музея, дата `ММ-ДД` | ключ строго `ММ-ДД` |

## 5. Как сдать работу

1. Ветка `<твоя подпись>/<тема>` от свежего `main`, коммит обычным `git commit` своей подписью.
2. Проверить у себя: `npm ci && npm run build` — без ошибок.
3. Заявка: `gh pr create`, сразу `gh pr merge <N> --auto --squash`.
4. Проверка `sborka-i-ssylki` (сборка + битые внутренние ссылки, порог 0) зелёная — заявка сливается
   сама, сайт выкладывается сам. Красная — чини в той же ветке. В `main` напрямую не пишется.
5. Сдача = слитая заявка. Результат — ссылкой на живую страницу, проверенной на открытие.

## 6. Чего не делать

- Не верстать страницу руками и не вписывать стили в страницу — вид только в `public/assets/*.css`.
- Не менять шаблоны `src/pages/` без задания: их делают помощники-дизайнеры по `museum-core`.
- Не добавлять скрипты, проверки и конвейеры: служебного не становится больше (цель — не больше 15 скриптов).
- Не брать текст с Википедии, не накладывать текст на картинку, не обрезать имя музея.
- Не трогать чужой музей: зоны — `docs/agents/zones.json` в `AI_Projects`.
