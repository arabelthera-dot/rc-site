# Генератор игр по жанрам — общий код

Одна команда собирает все игры музея по расписанию:

```
node tools/zhanry/sobrat-vse.mjs [музей]     # по умолчанию izobreteniya
```

Ручной правки под день нет: всё, что меняется от дня к дню, берётся из карточки
`src/content/dni-shablon/<музей>/ММ-ДД.yaml`. Последняя строка вывода — «Генератор собрал N из M игр без ручной правки»
(M — дни расписания, у жанра которых есть модуль; дни без модуля печатаются как «пропускаю»).

## Что где

| Файл | Что делает |
|---|---|
| `tools/zhanry/raspisanie.yaml` | день → жанр и вариация по карте r554: `01-13: G7а` |
| `tools/zhanry/sobrat-vse.mjs` | читает расписание, вызывает модуль жанра, пишет файлы, подключает игру в карточку дня |
| `obshchee/dannye.mjs` | общее для всех жанров (ниже) |
| `<жанр>/zhanr.mjs` | модуль жанра: вариации, данные игры, разметка, 3D-сцена |
| `<жанр>/shablon.html` | разметка игры с полями `{{pole}}` |
| `<жанр>/dvizhok.js` | движок игры в браузере, один на все дни; данные дня — JSON в разметке |
| `<жанр>/zhanr-<жанр>.css` | вид игры |

Готовые жанры: `masshtab/` — G7 «Угадай и проверь масштабом» (а глубина, б мороз; эталоны — `masshtab/etalony.yaml`),
`opyt/` — G14 «Опыт» (а раскрути, б нагрей). G12 «Крути ручку» — отдельная ветка r558 (`tools/zhanry/sobrat.mjs` там).

## Что пишет генератор

- `src/data/igry/<музей>/<жанр>-ММ-ДД.html` — разметка из шаблона;
- `public/muzei/<музей>/igry/<жанр>-ММ-ДД.js` — копия движка с шапкой «Сгенерировано…» (править движок в `tools/zhanry/<жанр>/`);
- `public/assets/zhanr-<жанр>.css` — копия стиля;
- в карточке дня правкой двух строк: `igra.vtoraya: <жанр>-ММ-ДД` (игра встаёт под игрой дня, та не тронута) и `zhanr-<жанр>` в `igra.css`;
- если есть 3D-модель предмета — ещё сцена `public/muzei/<музей>/igry/rc3d/scen/zhanr-ММ-ДД.json` и `igra.rc3d`.

## obshchee/dannye.mjs

- `obshchieDannye(d)` — общие поля дня: предмет (из крошки), заголовок, плашки, удары истории (история + факты),
  факт дня (граница первенства), картинка (обложка или первый кадр не портрет), все кадры дня `kadry`.
- `kadrPo(x, /слова/)` — кадр, в `alt` которого есть нужное жанру (гиротрон, волчок); нет — обычная картинка.
- `vybratUdary(x, { min, max, chtenie })` — удары под игру: не меньше min, не больше max, суммарно не длиннее chtenie знаков.
- `shablonom(shablon, pole)` — `{{x}}` экранированный текст, `{{{x}}}` готовая разметка; неизвестное поле — ошибка.
- `jsonVHtml(o)` — JSON для `<script type="application/json">`.
- `chislo('1 027,5 м')` → 1027.5; `krasivo(x, znakov)` — «1 027», минус «−»; `god(v)` — год ли это (1000–2100).
- `modelDnya(muzei, den)` — есть ли `public/muzei/<музей>/igry/rc3d/assets/models/predmety/ММ-ДД.glb`.
- `podklyuchit(put, { imya, css, rc3d })` — правка карточки дня; чужую `vtoraya` или чужую `rc3d` не трогает (ошибка).

## Как добавить жанр

1. Папка `tools/zhanry/<id>/` с четырьмя файлами по образцу `opyt/`:
   - `zhanr.mjs` — `export const id, css, nazvanie, faily` и функции `dannye(d, den, { variaciya })`, `html(x, shablon)`,
     `scena3d(x, model)`. `dannye` возвращает `{ ...obshchieDannye(d), variant, udary, n, cifra, fakt, … }`; если дню
     жанра нечего показать — `throw new Error('почему')`, генератор напишет «НЕ собрано» и пойдёт дальше.
   - `shablon.html` — корень `[data-zhanr-<id>] data-sostoyanie="zhdet"`, весь текст под сценой, JSON в `.z?-dannye`.
   - `dvizhok.js` — состояния `zhdet → idet → rezultat → fakt`, в `fakt` ставит `data-sekund` (время игры, цель 60–120 с).
   - `zhanr-<id>.css`.
2. Строка в `ZHANRY` в `sobrat-vse.mjs`: `G9: { modul: uvelich, variacii: { а: 'metall', б: 'kaplya' } }`.
3. Дни — в `raspisanie.yaml` (обычно они там уже есть по карте r554).
4. `node tools/zhanry/sobrat-vse.mjs`, потом сборка сайта и проверка в браузере 390×844.

## Как подключается 3D

Код не меняется. Конвейер моделей кладёт `public/muzei/<музей>/igry/rc3d/assets/models/predmety/ММ-ДД.glb` →
следующий запуск генератора видит файл, вызывает `scena3d(x, model)` жанра, пишет сцену `rc3d/scen/zhanr-ММ-ДД.json`
и добавляет в карточку `igra.rc3d` (scen, h2, lead, alt, razmer). На странице над игрой появляется блок 3D с кнопкой
«Играть» (движок rc3d грузится только по кнопке), 2D-игра остаётся ниже. Модель убрали — следующий запуск снимает
и `igra.rc3d`, и json сцены (только свою: `scen` начинается с `zhanr-`).
