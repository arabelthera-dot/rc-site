# Медиа вне сайта

Ролики и звук, на которые на новом сайте не ссылается ни одна страница: медиа старых страниц, ещё не перенесённых
(«Девятый вал», «Радуга», «Чёрное море» Айвазовского, экспедиция Дежнёва 1648), и вертикальные/запасные версии для
соцсетей. Вынесены из `public/` 20.10.2026 (задача T, Р49: вес сборки 933 из 950 МБ) — не удалены.

Переносишь такую страницу на сайт — верни нужный файл тем же путём в `public/` (`git mv media-vne-sajta/<путь> public/<путь>`).
Ролики по Р38 уходят на VK Видео и Rutube (аккаунты — М33).
